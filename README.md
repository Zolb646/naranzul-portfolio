# Naranzul portfolio

Two independent Next.js applications share this repository:

| Directory | Purpose | Vercel project |
| --- | --- | --- |
| `naranzul` | Thresholds interior-design portfolio preview | `naranzul-portfolio` |
| `designer-intake` | Mongolian / English content worksheet with local drafts and JSON/TXT exports | `naranzul-content-brief` |

Set each Vercel project's Root Directory to the matching folder. The intake application stores answers only in the designer's browser and downloads files; it does not submit them to the portfolio or any backend. Photographs and documents are collected as shared folder links.

The portfolio remains an explicitly labelled concept preview until actual designer information and project assets are supplied. No fictional biography or generated portrait has been added.

See each application's README for local commands and content workflows.
